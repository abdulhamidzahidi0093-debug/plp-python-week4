# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

This repository contains my Week 4 Python assignment. It demonstrates how to create and use functions, parameters, return values, and default arguments.

## Files

- welcome.py: Uses a welcome function to greet three people.
- toolbox.py: Contains three functions to double numbers, check passing scores, and greet people.

## My Reflection

The greet function was the hardest for me to write because I had to understand how default parameters work. I learned that a function can use a default greeting when no other greeting is provided.
